# Lare — Команды

Вводите команды `/…` в командной строке Lare Terminal (в вашей сессии PowerShell).
Результат каждой команды со слэшем появляется в отдельном окне; в терминале остаётся строка подтверждения.

## ИИ
- `/ai "запрос"` или `/ "запрос"` — ИИ отвечает и выполняет команды **в вашей оболочке**
  (каждая предложенная команда запрашивает подтверждение `[Y/n]` перед выполнением). Кавычки обязательны.

## Команды
- `/help` — это окно.
- `/ping` — проверка слоёв Lare (lare-shell, orchestrator, plugin-ping, ui.exe).
- `/config` — конфигурация (внешний вид, веб-поиск, ИИ, рынки).
- `/library` — архив сохранённых документов (можно открыть повторно).
- `/aichat` — AI Chat (общение между Lare-машинами в сети, с участием ИИ).
- `/open <target>` — открыть URL, папку или файл приложением по умолчанию. Без
  кавычек вокруг цели (в отличие от `/ai` выше): введите её как есть, даже с
  пробелами.
- `/web <query>` — искать запрос в браузере по умолчанию.
- `/show <markdown>` — открыть окно с указанным Markdown.
- `/find [<query>] [in:"<фраза>"] [folder:from-here]` — поиск файлов в реальном времени, отдельное окно.
- `/reset` — перезапустить сессию оболочки.
- `/nowin <запрос>` — ИИ отвечает текстом в терминале, без окна Markdown.
- `/calc` — калькулятор (плагин).

## Внешние инструменты (отдельное окно)
- `/markets` — инструменты финансовых рынков (поиск тикеров, отчёт по акции, список символов, скринер).
- `/netsec` — инструменты сканирования сети и диагностики (статус роутера, быстрое сканирование, определение ОС/версии, обнаружение хостов, поиск уязвимостей).
- `/pyping` — тестовый канал для инфраструктуры Python-инструментов (эхо сообщения).

## Всё остальное
- Любая строка, не начинающаяся с `/`, — это PowerShell, как обычно.
- Неизвестная команда со слэшем игнорируется молча.
